# fantasy-draft-analyzer
Compares fantasy football draft position (ADP) with actual PPR points to find the biggest steals and busts. Python, pandas, SQLite.
## Questions this project answers
1. Which players beat their draft spot by the most, and which busted hardest?
2. Which position gives the most value late in drafts?
3. Do first round picks actually pay off?
4. Is waiting on a QB a smart move?

## Tools
Python, pandas, SQLite, GitHub Codespaces
